# v0.7.2 · 现钱与交货天数版（单机试玩）

玩家反馈资金「点」和工期「格」不够直观，本版改用现钱与游戏天数，让花费、等待和交期更容易理解。

## 这次调整

- **金额**：顶部以钱币图标配「现钱160」；选项、货单、对白和账本用「花费20」「实付133」「待还66」，不再显示资金单位「点」。
- **时间**：原先「工期3/10格」显示为「距交货还剩7天」。到期当日显示「今日须交货」；超过期限显示「已逾期2天」并以暖色提醒。交货后显示交货用时或逾期天数。
- **经营选择**：明确花费和耗时，例如「花费8 · 耗时1天」；订单列出几天内交货和逾期每天扣款。议价仍只显示谈成可省多少钱，不公开成功率。
- **货色**：仍为0—100的评分；差距和运输损耗用「分」表示，与金额区别。
- **帮助**：说明「金额与天数为游戏设定，贸易流程经过压缩」。阅读、思考、看帮助不会让日子自行流逝，确认经营行动才推进天数。

这是显示和说明调整。原有成本、预付款、借款、加工收益、随机概率、订单期限与结算算法均未改变；金额不对应真实银两，天数也不作为历史工序耗时依据。此前规划里的抽象「格」保留在历史文档中，当前可玩版本以本说明为准。

## 下载与运行

下载 Assets 中的 **13-Hongs-Manager-v0.7.2-Windows-x64.zip**，解压到新文件夹，双击 **启动游戏.cmd**。旧版Windows触摸设备可用 **启动兼容模式.cmd**；F11可切换全屏。

完整包包含便携引擎、全部美术与两首背景音乐，无需另装Godot或Python。保留v0.7.1音乐开关与陈叔收尾的触摸去重修复；兼容入口仍使用30帧。历史Release保留，不覆盖旧包。

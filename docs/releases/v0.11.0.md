# v0.11.0 · 工序手势与操作衔接版（单机试玩）

补齐六道工序和合盖动作。从取工具到实际操作连在一起，鼠标按住拖动或单指触摸都能完成。

## 这次更新

- **摊叶看形**：从中间向左右拨开茶样，观察叶形与碎叶。
- **轻捻辨湿**：短距离来回捻两回，完成后显示原有干湿线索。
- **拨匀炭火**：用火钳向两侧拨开炭火，再继续翻茶。
- **移筛回凉**：竹筛移到接茶处稍停，再移到回凉小台，松手后完成加工。
- **铺衬抹平**：衬料拖入箱口，松手展开，再从亮点抹平。
- **悬停倒茶**：将茶篓移到箱口上方，按住约1秒，装满后松手；离开箱口会暂停倾倒。
- **拖盖接封绳**：箱盖对齐后松手，直接进入现有的两道封绳动作。
- **取用衔接**：按住工具盘中的当前道具可直接拖入工序；轻触也能把工具放到附近供再次抓取，无需另点开始。

保留晃杯、绕盘翻茶、描绳和三轮箱组装船。中途松手、打开帮助或原画后可继续；失误不额外扣币或耗天数，手速不改变经营结果。

## 下载与运行

在 **Assets** 下载 **13-Hongs-Manager-v0.11.0-Windows-x64.zip**，完整解压到新文件夹，双击 **启动游戏.cmd**。旧版Windows触摸设备可用 **启动兼容模式.cmd**，F11切换全屏。

完整包包含便携Godot、全部美术、离线历史参考图与两首完整MP3，无需安装Godot或Python。Main Theme与13 Hongs依次循环。

# v0.9.0 · 订单故事与装船演出版（单机试玩）

三份茶单有了不同的委托缘由，经营途中的提醒和结尾会回应你这一单的真实结果。

## 这次更新

- **老客又来订茶**：守约交齐，也要照应本钱。
- **黄埔有船等着茶**：急单愿加价，封箱和驳运时会提醒实际剩余交期。
- **这一回，要照茶样交**：品质严苛的客人请怀特把关，验货、复焙和路上防潮都有了故事缘由。
- **可回看的来信**：开场图文委托卡，接单后随时查看来信；阅读不花钱、不耗天数。
- **如实收尾**：交期、货色、箱数、折价或转售，与实际盈亏分别回应。按约交货仍可能亏本，赚钱也不等于完全履约。
- **封箱与装船演出**：铺衬、落茶、压盖扎绳；阿顺按4＋3＋3箱点货装船，全部点齐后选择驳运路线。
- **操作保护**：动作播完再计数，重复点击不多扣钱；打开来信或原画暂停工序，退出本局取消未完成动作。

故事与人物是游戏虚构。经营价格、期限、货色、风险和结算算法保持不变；保留晴雨场景、真实历史参考画、男女主角、双曲背景音乐和触摸兼容入口。

## 下载与运行

在本页 **Assets** 下载 **13-Hongs-Manager-v0.9.0-Windows-x64.zip**，完整解压到新文件夹，双击 **启动游戏.cmd**。旧版Windows触摸设备可用 **启动兼容模式.cmd**，F11切换全屏。

完整包包含便携Godot、全部游戏美术、离线原画参考与两首MP3，无需安装Godot或Python。

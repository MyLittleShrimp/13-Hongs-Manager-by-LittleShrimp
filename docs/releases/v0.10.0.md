# v0.10.0 · 拖拽与手势互动版（单机试玩）

这一版可以亲手把茶箱拖上船、晃杯看茶、绕盘翻茶和沿路封绳。支持鼠标按住拖动，也支持单指触摸。

## 这次更新

- **拖箱上船**：十箱分为4＋3＋3三组，每轮排列不同。把岸上的整组茶箱拖到船上同形轮廓，对齐变绿、松手装妥后计数，三轮完成再选择驳运路线。
- **轻晃茶杯**：点击「看汤色」，按住茶杯左右轻晃三次，松手后记下观察。新增可随手势移动的青花茶杯。
- **绕盘翻茶**：复焙的翻茶步骤改为按住竹铲沿茶盘绕一圈，顺逆方向均可；随后继续原有收茶回凉流程。
- **沿路封绳**：沿两道绳路描画，绳线随着轨迹出现；中途松手可从亮点继续。
- **可放心重试**：箱组拖偏会放回岸上；手势练习不额外收费、不耗游戏天数，操作快慢不影响货色与盈亏。
- **暂停与触摸保护**：阅读帮助、来信、原画或切出窗口时暂停，回来重新抓取继续；第二根手指、触摸附带的鼠标事件和重复松手不会多记一批货。

沿用三类订单故事、两位主角、晴雨场景、历史原画参考和双曲背景音乐。经营价格、期限、货色、随机风险与结算规则保持不变。

## 下载与运行

在本页 **Assets** 下载 **13-Hongs-Manager-v0.10.0-Windows-x64.zip**，完整解压到新文件夹，双击 **启动游戏.cmd**。旧版Windows触摸设备可用 **启动兼容模式.cmd**，F11切换全屏。

完整包包含便携Godot、全部美术、离线原画参考与两首MP3，无需安装Godot或Python。启动先播Main Theme，随后播放13 Hongs，两首依次循环。

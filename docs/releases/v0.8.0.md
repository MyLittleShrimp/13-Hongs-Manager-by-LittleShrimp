# v0.8.0 · 外销画与晴雨场景版（单机试玩）

金额补上「币」，看场景时能对照历史原作，晴天、阴天与风雨也有了各自的画面。

## 这次更新

- **金额更易读**：现钱124币、谈成可省11币、花费20币、待还66币。选项、人物对白、货单、借款、账本和结算统一补全单位；时间继续使用游戏中的「天」。
- **看画与看场景**：七个场景均可点击「外销画 · 看看场景」。窗口展示4幅真实历史作品的数字图像，并提供放大、观察提示、收藏机构、年代、藏品号及来源说明。所有图片可离线查看。
- **晴雨对应背景**：以现有场景为参考，用内置ImageGen新增14张天气背景；连同原图，七个场景各有晴天、阴天、风雨三种画面。室内看得到窗外天气，人物和茶箱的光色也随场景变化。
- **天气与事件一致**：遇到阵雨切换风雨背景；雨后平稳航段显示「雨势暂歇」；船舱漏水不会凭空改变天气。背景过渡不重新抽取经营随机数。
- **延续已有体验**：男女主角、剧情、验茶与复焙演出、随机盈亏、两首背景音乐和Windows触摸兼容入口继续保留。

「币」为游戏记账单位，不对应真实历史币值；成本、概率、货色、期限及结算算法未变。参考画涉及不同年代，作为题材对照；游戏中的房间、角色、工序与天气属于创作。来源及使用范围见 [外销画参考来源](../外销画参考来源.md)。

## 下载与运行

在本页 **Assets** 下载 **13-Hongs-Manager-v0.8.0-Windows-x64.zip**，完整解压到新文件夹，双击 **启动游戏.cmd**。旧版Windows触摸设备可用 **启动兼容模式.cmd**；F11切换全屏。

完整包包含便携引擎、全部游戏美术、历史参考图和两首MP3，无需安装Godot或Python。

# v0.7.0 · Windows 单机试玩版（含双曲背景音乐）

本次完整包包含 v0.5 之后的音乐、茶市剧情、验茶结果和工序演出更新。

## 下载与运行

在本页 Assets 中下载 **13-Hongs-Manager-v0.7.0-Windows-x64.zip**，完整解压到一个新文件夹，双击 **启动游戏.cmd**。全屏使用 **启动全屏体验.cmd**。已包含便携 Godot、全部游戏素材与导入资源，Windows 64 位系统无需安装 Godot 或 Python。

`Source code (zip)` / `Source code (tar.gz)` 是 GitHub 自动生成的源码快照；普通试玩请下载上面的 Windows 完整包。

## 本版更新

- 两首背景音乐随包附带：开场播放 Main Theme，随后播放 13 Hongs，两首按顺序循环。角色选择、切换场景及重新开张保持播放进度。
- 「声音设置」可暂停／续播音乐、调整音量及单独开关点击音效；默认音乐开启，音量35%。
- 茶市可问货源、船期、货色；议价选项直接显示谈成能省多少点，新增成交回应、付款递单和后续对白。
- 验货后中央大字显示货色范围或准确值、订单门槛及风险提示。
- 复焙后显示处理前后对比；新增看叶形、辨干湿、看汤色、拨炭、翻茶和收茶回凉六项工序演出。
- 阿砚／阿宁两位主角、随机行情、盈亏、借赊周转、两次复焙及折价／转售流程保留。
- 游戏内版本号、发布标题、标签和包名统一为 v0.7.0。

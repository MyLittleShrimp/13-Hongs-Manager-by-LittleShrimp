- 使用Godot原生InputEventScreenTouch注入，不等同于真实触摸屏驱动测试。
- 空闲阈值通过推进时间状态验证，不宣称完成全天运行。
- v0.2实际渲染在1920×1080验证；继承逻辑画布缩放策略，其他尺寸仍需复核。
- 测试桌面为Compatibility/OpenGL，设备日志识别NVIDIA RTX 3050 Laptop GPU；不代表馆内硬件性能。
- 本机受限环境仍有Godot根证书存储读取消息；游戏完全离线，已测流程未受影响。
- 尚无真人3–5分钟完成率、学习效果、可达性、8小时连续运行或正式安装包验收。

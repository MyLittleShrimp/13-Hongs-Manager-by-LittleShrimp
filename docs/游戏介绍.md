# 《十三行 · 茶船将发》游戏介绍

## 正式介绍

《十三行 · 茶船将发》是一款以广州十三行贸易为背景的二维剧情策略经营游戏，面向博物馆互动体验设计。玩家可以选择阿砚或阿宁，扮演行号的新任采购管事，从陈叔手中接过第一笔外商茶单，走进茶市挑货议价，亲手验茶、复焙加工、装箱封绳，再与船家一道应对江上风雨，将茶货送到商船交接人手中。货色、成本、工期与随机事件共同影响每一单的结局：茶叶不达标时可以继续处理或协商折价，资金吃紧时可以寻求周转，但每次补救都需要付出代价。游戏将人物对话、场景操作与真实盈亏计算融入一段茶叶贸易旅程，让观众在做选择、算生意、担风险的过程中，感受十三行贸易的协作与经营智慧。

## 精简介绍

一笔茶单，一段由你作主的生意。《十三行 · 茶船将发》是一款以广州十三行贸易为背景的二维剧情经营游戏。选择阿砚或阿宁，体验采买、验茶、加工、封箱与驳运，在货色、船期、成本和风雨之间作出取舍。每次开张都有新的行情，每一单都有赚与亏的可能。

## GitHub 仓库简介

以广州十三行贸易为背景的 Godot 2D 剧情经营游戏：选择男女主角，体验茶叶采买、验货、加工、装箱与驳运，在随机行情与风险中经营一笔真实有盈亏的茶单。

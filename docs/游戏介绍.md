# 《十三行 · 茶船将发》游戏介绍

## 正式介绍

《十三行 · 茶船将发》是一款以广州十三行贸易为背景的二维剧情策略经营游戏，面向博物馆互动体验设计。玩家可以选择阿砚或阿宁，扮演行号的新任采购管事，从陈叔手中接过第一笔外商茶单，走进茶市挑货议价，轻晃茶杯观察汤色，绕盘翻茶、沿绳路封箱，再把一组组茶箱拖上船。与船家一道应对江上风雨，将茶货送到商船交接人手中。货色、成本、工期与随机事件共同影响每一单的结局：茶叶不达标时可以继续处理或协商折价，资金吃紧时可以寻求周转，但每次补救都需要付出代价。游戏将人物对话、手势操作与真实盈亏计算融入一段茶叶贸易旅程，让观众在做选择、动手操作和承担风险的过程中，感受十三行贸易的协作与经营智慧。

## 精简介绍

一笔茶单，一段由你作主的生意。《十三行 · 茶船将发》是一款以广州十三行贸易为背景的二维剧情经营游戏。选择阿砚或阿宁，体验采买、验茶、加工、封箱与驳运，在货色、船期、成本和风雨之间作出取舍。每次开张都有新的行情，每一单都有赚与亏的可能。

## GitHub 仓库简介

以广州十三行贸易为背景的 Godot 2D 剧情经营游戏：选择男女主角，体验茶叶采买、验货、加工、装箱与驳运，在随机行情与风险中经营一笔真实有盈亏的茶单。

## 当前版本信息

- 单机茶叶篇 v0.10.0，Godot 4.7.2，支持横屏鼠标与单指触摸。
- 7处场景、2位可选主角、4位NPC，配合人物微动、工具操作和天气效果。
- 支持货色补救、借款与赊账、折价／转售、详细账本和分支收尾。
- 老客稳单、赶船急单、茶样严苛单各有委托故事；封箱与分批装船有连续动作，收尾回应实际交货与盈亏。
- 四类手势：拖箱匹配、轻晃茶杯、绕盘翻茶、沿路封绳。操作失误可重试，经营结果继续取决于选择与随机事件。
- 晴、阴、风雨对应七处场景，可离线查看4幅历史原作参考；包含两首循环背景音乐及Windows触摸兼容入口。
- 当前完成茶叶篇可玩原型；瓷器、丝绸、数字分身、现场硬件联调与正式发行待后续。
- 人物、场景与数值是游戏化艺术设定，具体历史内容待馆方审定。
